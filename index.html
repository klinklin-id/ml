Regulasi

Cara peringkat dihitung

Komponen klasemen

  • Match Point — tiap seri Best of 3 yang dimenangkan bernilai +1 poin, kalah 0 poin.
  • Match W-L — rekor seri menang berbanding seri kalah, contoh 13 - 3.
  • Net Game Win — total game menang dikurangi total game kalah.
  • Game W-L — rincian menang-kalah game sepanjang babak reguler.

Urutan penentuan

  • Match Point terbesar menempati posisi teratas.
  • Net Game Win dipakai saat Match Point sama.
  • Head-to-head dipakai saat keduanya masih sama; tim yang diurutkan lewat cara ini diberi tanda H2H.

Jalur ke playoff

  • Peringkat 1–2 — langsung ke upper bracket ronde dua.
  • Peringkat 3–6 — mulai dari ronde satu playoff.
  • Peringkat 7 ke bawah — tereliminasi.

Cara kerja bracket

  • Upper bracket — menang lanjut, kalah turun ke lower bracket.
  • Lower bracket — kesempatan terakhir; kalah sekali langsung gugur.
  • Grand Final — juara upper bracket melawan penyintas lower bracket. Menang jadi juara 1, kalah juara 2.
